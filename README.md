# Signal & Serif Design System

A design system built for a bilingual (EN/FR) SEO and organic-growth marketing portfolio: design tokens, core UI components, 24 ARIA APG interactive patterns, and a 21-chart data visualization gallery.

## Contents

- `index.html` — the full reference manual. Every component ships with copy-paste-ready markup, styles, and behavior code, plus purpose/notes for when to use it. Open this file directly in a browser, or serve the repo with GitHub Pages to browse it online.
- `source.html` — the original design system page the reference manual was generated from.

## Structure

The reference manual covers:

- **Foundations** — design tokens (light/dark), typography scale, spacing & grid
- **Core components** — buttons, tags, form-field states, stat tiles, cards, a wired dashboard line chart, and a wired contact form
- **Interactive patterns (ARIA APG)** — 24 patterns from the W3C ARIA Authoring Practices Guide, each with real keyboard model and ARIA state management
- **Chart gallery** — 21 chart types built to a consistent method: form follows data, categorical color validated for colorblind-safe separation, consistent mark specs, hover/focus tooltips throughout

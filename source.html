This document defines the visual language before a single page of the site gets built: a near-monochrome surface with one accent doing all the signalling, a serif for editorial gravitas paired with a technical sans and mono, and a component set built for both narrative case studies and the dashboards this portfolio needs to show its analytics work credibly. Data-series palette — dashboards & multi-line charts only

Fixed hue order, assigned in sequence, never cycled. Slot 1 is the brand accent, so a single-series chart and a multi-series dashboard read as one system. Cap at 3 hues for scatter/bubble/small-multiples; direct-label from 4 series on; fold anything past 6–8 into “Other” or facet instead of adding a hue.

03

Grid & spacing

An 8px base unit and a 12-column grid. Radii stay small and deliberate — hairlines and whitespace do the separating, not shadows or heavy rounding.

space-2 · 8pxTag padding, icon gaps
space-4 · 16pxComponent internal padding
space-5 · 24pxCard padding, stack gaps
space-6 · 32pxSection-head gap
space-7 · 48pxBetween major blocks
space-9 · 96pxSection vertical padding (desktop)

12-column grid, 8px gutter, 1280px max width

Do
  • 2px radius on inputs and buttons, 4px on cards — sharp enough to read as technical.
  • Separate cards with a 1px hairline in the grid gap, not a drop shadow.
  • Reserve full-pill radius for tags and status chips only.
Don't
  • Round every surface to rounded-xl — it reads as generic SaaS, not this brand.
  • Stack soft shadows for elevation; use the surface-2 token or a border instead.
  • Let two adjacent hairlines touch without the 1px shared gap defined above.

08

Motion, interaction & accessibility

Rules, not decoration — every interaction here earns its place or it's cut.

Motion
  • 150ms ease for hover/focus state changes — nothing longer.
  • No entrance animation on scroll; content is present, not performed.
  • prefers-reduced-motion disables all transitions.
Interaction
  • Every chart ships a hover tooltip and a table-view fallback — nothing is hover-only.
  • 2px accent focus ring, 2px offset, on every interactive element.
  • Hit targets ≥ 24px even when the visible mark is smaller.
Accessibility
  • Body text holds ≥ 4.5:1; large text and graphic elements hold ≥ 3:1 — checked, not eyeballed.
  • Status color always ships with an icon and a label, never hue alone.
  • Semantic HTML first: nav, article, real headings — ARIA fills gaps, doesn't replace them.

    Chart gallery

    All 21 chart types from the storytellingwithdata.com chart guide, built per the dataviz method: form chosen by the data's job, color assigned by that job and validated, thin marks with real spacers, and a legend wherever identity matters. Every mark below carries a native hover tooltip with its exact value and a generous hit area — the fuller custom crosshair-and-table treatment (keyboard-steppable, with a data-table fallback) lives on the dashboard line chart in section 05, so it isn't rebuilt 21 more times here. Data is real where the career record supports it, clearly marked illustrative where it doesn't.
